## THE GOLDEN RULE — NEVER DELETE, ALWAYS REPAIR

> **You must NEVER remove a `[Ri = ...]`, `[N_R_i = ...]`, or `[F_R_i = ...]` bracket. Deletion is forbidden in all cases.** Every reproductive value mentioned in the text deserves a correct annotation. When an annotation is wrong, you REPAIR it using one of exactly three actions, chosen in this priority order:
>
> 1. **EXPAND / FIX the bracket** — when the correct words already exist in the prose. Adjust the span so the bracket captures the verbatim words that satisfy the entity definition. (Most common.)
> 2. **EDIT the prose** — when the words needed to satisfy the entity definition are *genuinely absent* from the sentence. > **WORD-FORM LOCK (highest-frequency real-world failure — check FIRST on every bracket):** number words and digits are NEVER interchangeable, in either direction. `single`/`one` ≠ `1`; `three to four` ≠ `3-4` ≠ `3 to 4`. ### G1e — F_R_i is an offspring count, not an event frequency

F_R_i contains offspring words + a time unit, WITHOUT an event-count word.
→ **CRITICAL**: relabel `[F_R_i = X]` → `[Ri = X]`. `RELABEL`. Prose unchanged.

- ❌ `"three or four eggs per year [F_R_i = three or four eggs per year]"` → `[Ri = three or four eggs per year]`
- ✅ `[F_R_i = single clutch of eggs each year]` — event word "clutch" present, correctly F_R_i (the embedded "of eggs" does NOT trigger G1e)

### G1d — Mixed labels in single bracket

Annotation contains `;` separating two labels.
→ **CRITICAL**: split into two brackets, each placed immediately after its own verbatim span. `repair_mode = "FIX_SPAN"`.
→ Example: `"females produce 2 pups per litter once per year [N_R_i = 2 pups per litter; F_R_i = once per year]"` → `"...2 pups per litter [N_R_i = 2 pups per litter] once per year [F_R_i = once per year]"`

### SPAN-A — Qualifier missing from annotation

Prose has an epistemic qualifier immediately before the value; annotation omits it.
→ **CRITICAL**: add the qualifier to match the verbatim prose span. `FIX_SPAN`.

### SPAN-B — Qualifier in annotation, absent from prose

→ **CRITICAL**: remove the qualifier from the annotation value. `FIX_SPAN`.

### SPAN-C — Value written differently (digit vs word, etc.)

→ **CRITICAL**: replace annotation value with the exact verbatim prose span. `FIX_SPAN`.

### SPAN-D — Value appears nowhere in the sentence — **REPAIR, DO NOT DELETE**

The annotation value is not verbatim in the sentence AND no obvious typo/variant maps to it.
→ **CRITICAL.** Do NOT delete. Instead:

1. Is there a *different* quantified reproductive value in the sentence that this bracket clearly intends? → set the bracket to that verbatim value (and correct label).
2. Is the value almost-verbatim (digit/word or qualifier mismatch)? → treat as SPAN-A/B/C and fix.
3. Is the value real biology but the words are simply missing from the prose? → **MODE 2: EDIT PROSE** to state the value, then bracket it. Log the edit.
4. Only if the value is genuinely nonsensical / unrecoverable → `FLAG_MANUAL`, keep the bracket in place for a human. **Still never removed.**

## CORRECTION PRIORITY ORDER

When multiple issues apply to one annotation:

1. **G1a / G1c / G1e** — fix the label first.
2. **N_R_i-BARE / F_R_i-NOTIME** — make the span definition-compliant (MODE 1 expand, else MODE 2 edit).
3. **SPAN-A/B/C** — align the value to the exact (possibly edited) prose span.
4. **G1b** — fix frequency expression.
5. **G1d** — split mixed labels.

**Combined example — G1a + SPAN-A:**

```
prose:        "females produce approximately 300 eggs per year [N_R_i = 300 eggs per year]"
step 1 G1a:   [Ri = 300 eggs per year]                ← label fixed
step 2 SPAN-A:[Ri = approximately 300 eggs per year]  ← qualifier added from prose
final:        [Ri = approximately 300 eggs per year]
```
